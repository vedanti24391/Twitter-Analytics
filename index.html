Twitter Analytics Dashboard

Power BI Data Analytics Project

Project Overview

This project is a Twitter Analytics Dashboard developed using Microsoft Power BI. The dashboard analyzes tweet engagement, interactions, media performance, engagement trends, and high-performing tweets.

The project consists of six analytical tasks designed to demonstrate data cleaning, data modeling, DAX calculations, filtering, visualization, and business insight generation.

Tools & Technologies

Power BI DAX Power Query Excel Data Analysis Data Visualization

Key Analysis

  • Tweet Interaction Breakdown by Category
  • Engagement Rate Comparison – App Opens vs No App Opens
  • Media Interaction by Day of Week
  • Replies, Retweets and Likes Comparison
  • Monthly Engagement Rate Trend – Media vs Non-Media
  • Top 10 Tweets by Engagement

Key Skills Demonstrated

  • Data cleaning and transformation using Power Query
  • DAX calculated columns and measures
  • Date and time analysis
  • Conditional filtering
  • Interactive Power BI visualizations
  • Business-oriented data analysis
