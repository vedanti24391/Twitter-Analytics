TWITTER ANALYTICS PROJECT DESCRIPTION

Built an interactive 3-page Twitter Analytics dashboard in Power BI to analyze tweet reach, engagement, posting behavior, and content performance.

Used Power Query for data cleaning and transformation, created a dedicated Date Table and data model, and developed DAX measures for key KPIs including impressions, engagements, likes, retweets, replies, engagement rate, and average impressions per tweet.

Dashboard pages:
1. Twitter Overview
2. Twitter Engagement Analysis
3. Tweet & Content Performance

Key analytical areas:
- Daily tweet and engagement trends
- Engagement by posting hour and day
- Engagement composition
- Top tweets by impressions, likes, and engagement
- Tweet volume by hour and day
