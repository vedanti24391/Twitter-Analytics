# Twitter Analytics Dashboard — Power BI

## Project Overview

This project presents an interactive **Twitter Analytics Dashboard** built in Microsoft Power BI to analyze tweet activity, reach, engagement, and content performance.

The dashboard transforms tweet-level analytics data into a three-page reporting experience designed to answer:

- How is overall Twitter performance?
- When and how are users engaging?
- Which tweets and posting patterns perform best?

## Tools & Technologies

- **Power BI Desktop**
- Power Query — data cleaning and transformation
- DAX — calculated measures and date analysis
- Microsoft Excel — source dataset

## Data Preparation

The dataset was imported from Excel into Power BI and prepared using Power Query.

Key preparation steps included:

- Promoted the source row to column headers
- Corrected column data types
- Converted tweet timestamps into usable Date/Time values
- Created Tweet Date and Tweet Hour fields
- Created a dedicated Date Table for time-based analysis
- Built a one-to-many relationship between the Date Table and Twitter Data
- Handled missing numeric metric values appropriately
- Created reusable DAX measures for tweet and engagement metrics

## Key DAX Measures

DAX measures were created in Power BI to calculate and analyze tweet performance, engagement, audience interaction, and content trends.

### Core Performance Measures

* Total Tweets – Count of all tweets analyzed.
* Total Likes – Total number of likes received.
* Total Retweets – Total number of retweets received.
* Total Replies** – Total number of replies received.
* Total Impressions – Total impressions generated by tweets.
* Total Engagement – Combined likes, retweets, and replies.
* Engagement Rate (%)– Measures engagement relative to total impressions.
* Average Engagement per Tweet – Average engagement generated by each tweet.
* Average Likes per Tweet – Average likes received per tweet.
* Average Retweets per Tweet – Average retweets received per tweet.

### Content & Media Measures

* Media Views – Total views generated by media content.
* Media Engagement – Measures interactions generated through media content.
* Tweets with Media – Count of tweets containing media.
* Average Word Count – Average number of words used per tweet.

### Trend & Ranking Measures

* Monthly Engagement– Tracks engagement performance across months.
* Tweet Engagement – Calculates likes + retweets for individual tweets.
* Tweet Rank– Ranks tweets based on engagement to identify top-performing content.
* Top 10 Tweets – Identifies the highest-performing tweets based on engagement.

### Conditional Analysis

DAX was also used to support business-specific filtering and analysis, including:

* Weekday vs. weekend tweet analysis
* Even-numbered impressions
* Odd-numbered tweet dates
* Tweets with specific word-count conditions
* Top-performing tweets based on engagement

These measures enabled interactive dashboard analysis and helped identify high-performing content, engagement trends, audience interaction patterns, and content performance drivers.

## Key Insights

The dashboard highlights several useful patterns:
•	Different tweet categories can generate different types and levels of audience interaction.
•	Separating media and non-media tweets helps compare content-related engagement patterns.
•	Replies, retweets and likes provide complementary indicators of audience response.
•	Monthly and day-of-week analysis helps identify temporal engagement patterns.
•	Top-engagement analysis helps identify tweets generating stronger audience response.
